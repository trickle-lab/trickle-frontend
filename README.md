# Trickle Frontend

Web app for [Trickle](https://github.com/trickle-lab/trickle-contract), a Stellar streaming payments protocol. Connect a wallet, view active payment streams, create new ones, and withdraw or cancel them.

## Status
Next.js + TypeScript + Tailwind scaffold running. Wallet connect, streams dashboard, and create-stream form are open for contribution — see Issues.
